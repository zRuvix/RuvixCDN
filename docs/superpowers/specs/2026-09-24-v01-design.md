# v0.1 Design — zruvix-cdn skeleton, storage, CDN handler

Date: 2026-09-24
Status: implemented — merged to main 2026-09-24 (config, storage, server+middleware, CDN handler, healthz, build/deploy stubs).
Scope: CLAUDE.md §15 Roadmap item 1 (v0.1): config, server skeleton,
`/healthz`, storage layer + traversal tests, CDN handler.
Explicitly out of scope: auth (§8), dashboard pages (§7), mkdir/delete APIs.

Approach: **A — Roadmap-literal vertical slice.** Build in order
config → storage (with traversal tests) → server + middleware →
CDN handler → /healthz → Makefile/deploy stubs + .env.example.
Each package lands with its tests in the same change.

## 1. Repo bootstrap + config

- `git init`; `go.mod` (`module zruvix-cdn`, `go 1.23`).
  Note: local toolchain is go1.26.4 — keep the `go` directive at 1.23
  per CLAUDE.md unless a newer stdlib API forces a bump (then update CLAUDE.md).
- Layout exactly per §4: `cmd/cdn`, `cmd/hashpw` (stub, real bcrypt
  helper lands in v0.2), `internal/config|server|middleware|cdn|storage`,
  `web/` placeholder, `deploy/`, `docs/`. No new top-level dirs.
- `internal/config` parses §5 vars: `LISTEN_ADDR`, `DATA_DIR`, `PUBLIC_URL`,
  `ADMIN_USER` + `ADMIN_PASS_HASH` (parsed/validated, unused in v0.1),
  `SESSION_SECRET`, `SESSION_TTL`, `MAX_UPLOAD_MB`, `CACHE_MAX_AGE`,
  `TRUSTED_PROXIES` (CIDR list), `LOG_LEVEL`.
- Fail-closed: missing/invalid config → exit non-zero with a clear message (§3.5).
- `.env.example` documents every var; `.gitignore` covers `.env`, `*.env`,
  `bin/`, `dist/`, `data/`, `files/`, `*.tmp`, `*.log`.
- Local dev: `DATA_DIR=./data/files`.

## 2. Storage layer (`internal/storage`) — security critical

Sole package allowed to touch `os.*` with user-supplied paths (§3.3).

- **Validation:** dir segment `^[a-z0-9][a-z0-9_-]{0,62}$`, max depth 4;
  file name `^[A-Za-z0-9][A-Za-z0-9._-]{0,127}$`;
  reject empty segments, `.`/`..`, leading dots, backslashes, NUL bytes,
  absolute paths, reserved top-level names (`dash`, `healthz`,
  `favicon.ico`, `robots.txt`, names starting with `_` or `.`).
- **Resolution:** `filepath.Join(root, clean)` → require `root + separator`
  prefix → `EvalSymlinks` → re-verify prefix. Never follow symlinks out of root.
- **Allowlist (strict default, §9):** `png jpg jpeg gif webp avif ico svg
  css woff woff2 ttf mp4 webm mp3 pdf json txt`.
  NOT allowed: `js html htm xhtml xml` (same-origin threat note, §9).
  SVG served with sandboxing CSP (see §4 below).
- **Sniff:** first 512 bytes via `http.DetectContentType`, must be consistent
  with the extension.
- **API:** `Open` (read-only, the only func v0.1 handlers need), `Save`
  (atomic `*.tmp` + fsync + rename, explicit `overwrite` flag, caller
  enforces `MaxBytesReader`), `Delete` (refuse non-empty dirs), `Mkdir`,
  `List`, `Stats`. File perms `0644`, dir perms `0755`.
- **Tests (same change, per §14):** traversal (`../`, `..%2f`, encoded
  slashes, backslashes, NUL, very long names, reserved names),
  symlink-escape (in and out of root), sniff-mismatch, non-empty-dir delete
  refused, atomic-save no-overwrite default. Table-driven, `-race` clean.

## 3. Server skeleton + middleware

- `cmd/cdn/main.go`: load config, build server, graceful shutdown on SIGTERM.
- `http.Server` timeouts (mandatory, §13): `ReadHeaderTimeout 5s`,
  `ReadTimeout 30s`, generous `WriteTimeout` for large downloads,
  `IdleTimeout 120s`.
- Middleware chain: recover → realip (trust `X-Forwarded-*` only from
  `TRUSTED_PROXIES`) → log → sec-headers. Rate-limit middleware lands in
  v0.2 with login; structure the chain so it slots in.
- Logging: `log/slog` to stdout (method, path, status, bytes, duration,
  client IP). Never passwords/cookies/CSRF tokens.
- Router: Go 1.22+ `http.ServeMux`. `/dash/` stub in v0.1 (501 or login
  placeholder — real dashboard is v0.2/v0.3), `/healthz` → 200 `ok`,
  `/` → CDN handler. §2 test: `/dash/manage` never reaches the CDN handler.
- `gofmt` + `go vet` clean.

## 4. CDN handler (`internal/cdn`)

- Methods `GET`/`HEAD` only, else `405`.
- Resolve via `storage.Open`; ANY failure → plain `404`, never leak why.
- Serve with `http.ServeContent` (free `Range`, `If-Modified-Since`, `HEAD`).
- Weak ETag from `modtime-size`; no hashing on the hot path.
- Headers: `Cache-Control: public, max-age=<CACHE_MAX_AGE>`,
  `X-Content-Type-Options: nosniff`,
  `Access-Control-Allow-Origin: *`,
  `Cross-Origin-Resource-Policy: cross-origin`. **Never `Set-Cookie`.**
- SVG additionally: `Content-Security-Policy: default-src 'none';
  style-src 'unsafe-inline'; sandbox`.
- Content-Type from a fixed in-code extension map (not OS mime DB).
- `?v=anything` ignored (cache-buster).
- Directory URLs (`/logos/`) → `404`. `/` → minimal 404. Never list.
- Hot and boring: no sessions, no cookies, no templates (§3.4).
- **Tests:** `405` on POST/PUT/DELETE; `404` on missing + traversal
  (`../`, `..%2f`, encoded slashes); reserved names route away from CDN;
  `/dash/manage` → dash stub, not CDN; cache/ETag/CORS/CORP headers present;
  `Range` + `HEAD` work; no `Set-Cookie` on any CDN response.
